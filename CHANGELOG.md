# Changelog

## [1.0.0] - 2023-10-01

### Added
- Initial release of the PHP Cryptography Framework.
- Support for symmetric cryptography (AES-256-GCM, AES-256-CBC, ChaCha20-Poly1305, Camellia-256-GCM).
- Support for asymmetric cryptography (RSA, ECC, ECDH).
- Secure hashing algorithms (Argon2id, Bcrypt, HMAC).
- Key management features (KeyVault, Key Rotation, Key Derivation).
- File encryption capabilities with metadata.
- Database encryption for sensitive fields.
- Secure session handling.
- Integration with Laravel and other frameworks.
- Security utilities for random generation and auditing.
